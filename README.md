# Byte Dash

This is the deliverable for the STEAM assignment "Making a Game and Publish It as Github Pages."

## Game

Byte Dash is a small browser game made with one static `index.html` file. The player collects eight stars, avoids moving bugs, and reaches the GitHub Pages gate before the timer ends.

## Controls

- Arrow keys or WASD: move
- Space: dash
- P: pause
